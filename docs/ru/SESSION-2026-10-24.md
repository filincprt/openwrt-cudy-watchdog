## Текущий приоритет: проверить persistence Xray-exclude

Пользователь отложил прочую работу и попросил выполнить пункт 5: проверить сохранение пользовательских nftables-правил Xray-exclude после перезапуска firewall, а затем отдельно рассмотреть проверку после перезагрузки роутера. Сначала только read-only диагностика; не менять PassWall2 Auto, маршрут, стратегии zapret2 или бинарник.

Custom hook: /opt/zapret2/init.d/openwrt/custom.d/40-passwall2-xray-exclude.sh.

Задача hook: Xray outbound с socket mark low byte 0xff получает conntrack bit 0x01000000; соединения с этим bit обходят desync-обработку в postnat_hook и prenat_hook. Последний известный код:
    zapret_custom_firewall_nft()
    {
        nft -f - <<'NFT'
    insert rule inet zapret2 postnat_hook ct mark & 0x01000000 != 0 return comment "exclude PassWall2 Xray"
    insert rule inet zapret2 postnat_hook meta mark & 0x000000ff == 0x000000ff ct mark set ct mark | 0x01000000 comment "tag PassWall2 Xray outbound"
    insert rule inet zapret2 prenat_hook ct mark & 0x01000000 != 0 return comment "exclude PassWall2 Xray replies"
    NFT
    }

    zapret_custom_firewall_nft_flush()
    {
        :
    }

Ранее runtime-правила были видны и порядок выглядел корректным, но hit count не измерялся (правила без counter), persistence после firewall restart/reboot не проверена.

## Следующий безопасный порядок

1. Прочитать hook: cat /opt/zapret2/init.d/openwrt/custom.d/40-passwall2-xray-exclude.sh
2. Найти, где вызывается hook: grep -R -n 'zapret_custom_firewall_nft' /opt/zapret2/init.d/openwrt
3. Прочитать цепочки: nft -a list chain inet zapret2 postnat_hook и отдельно nft -a list chain inet zapret2 prenat_hook.
4. Перед тестом перечитать ha_watchdog.main.mode, passwall2.rulenode.default_node, статус служб zapret2 и passwall2-failover-watchdog. Если состояние неожиданное — остановиться и сообщить.
5. Только после фиксации исходного состояния выполнить отдельный firewall restart/reload test и убедиться, что правила снова появились. Не перезагружать роутер до успешного теста firewall restart и отдельной оценки безопасного доступа после reboot.
6. PassWall2 Auto не менять, маршрут вручную не переключать. Не обновлять zapret2 binary/strategies. Не удалять custom hook.

Учитывать особенности пользователя: короткие SSH-команды по одной, многострочная вставка иногда портит строки. Не коммитить пароли, URL вебхуков, токены или полные конфиги PassWall2.
