# История изменений

Это русская версия журнала изменений. Живое состояние и детали отдельных этапов сверяйте с оригинальным [CHANGELOG.md](../../CHANGELOG.md).

## 2026-10-22 — документирование исходной конфигурации

- Зафиксированы OpenWrt 25.12.6 на Cudy WR3000S AX3000 V2, ID основного `PusiSLgE`, резервного `fAk268mE` и прямого `_direct`, UCI-параметры и пути службы.
- Добавлена служба procd и цикл watchdog; включён автозапуск.
- Удалён старый watchdog из cron во избежание двух конкурирующих планировщиков; ежедневное обновление подписки PassWall2 сохранено.
- Для проверки узлов добавлен тайм-аут. Изолированные проверки возвращали HTTP 204 и код завершения 0.
- Добавлены ссылки `/usr/bin/geoip.dat` и `/usr/bin/geosite.dat` на файлы из `/usr/share/v2ray/`; связь с первоначальной проблемой не доказана.
- Автоматическое переключение при контролируемом отказе и последующем восстановлении остаётся непроверенным.

## 2026-10-22 — автозапуск и режим Auto

- После перезагрузки служба procd сообщала `running`, ссылки автозапуска существовали.
- Обнаружено сохранённое значение режима `primary`, которое пропускало проверки. Через помощник HA режим изменён на `auto`.
- После этого снова появились логи: оба узла возвращали HTTP 204, счётчики показывали `ok=3 fail=0`.
- Автозапуск подтверждён, но не контролируемый тест отказа и возврата.

## 2026-10-22 — случайные паузы и порог трёх сбоев

- В логике ядра/оболочки порог некоторых решений изменён с двух на три последовательных сбоя; восстановление осталось на трёх последовательных успехах.
- Фиксированная пауза заменена случайным ожиданием 5–15 секунд после полного цикла.
- Синтаксис ядра, оболочки и цикла проверен; служба перезапущена и сообщала `running`.
- После отдельных пустых результатов оба узла затем вернули HTTP 204; текущие счётчики сбросились к нулю, маршрут был основным, режим — `auto`.
- Первопричина пустых результатов не установлена. Случайная пауза не гарантирует избегание внешней блокировки.

## 2026-10-22 — телеметрия и отображение в HA

- Добавлены UCI-поля для результата HTTP, состояния online/offline, RTT, числа ошибок и времени проверки.
- Сводки основного и резервного узлов отображаются в существующем VPN-разделе HA.
- Для обновления карточек используется опрос UCI; он читает опубликованные данные и сам по себе не запускает VPN-проверку.
- Публикатор сбрасывает предыдущие отложенные изменения UCI перед установкой полного набора свежих значений, чтобы `/tmp/.uci/ha_watchdog_metrics` не рос из-за дублирующихся записей.
- Реальные значения вебхука намеренно не сохранены в репозитории.

## 2026-10-22 — ограничение частоты публикации метрик

- Ядро подключено к `passwall2-watchdog-publish-due`, который должен обновлять метрики примерно раз в случайные 180–300 секунд.
- В автоматическом режиме проверки узлов и решения о переключении остаются на каждом полном цикле; редкой стала именно публикация метрик.
- В ручных режимах `primary`, `backup`, `off` отдельная проверка метрик выполняется каждые случайные 180–300 секунд.
- Синтаксис ограничителя и ядра проверен. Фактическое разделение частых проверок и редкой публикации в `auto` ещё нужно подтвердить логами.
- Контролируемый тест отказа и восстановления всё ещё ожидает выполнения.

## 2026-10-22 — русская документация

- Создана русская версия основных страниц проекта отдельно от англоязычных оригиналов.
- Скрипты, UCI-ключи, ID, пути и команды оставлены без перевода, чтобы их можно было копировать и выполнять без изменения.
- Эталонные скрипты по-прежнему следует сравнивать с живыми файлами перед установкой.



## 2026-10-23 — исправлено исчерпание кэша временных тестовых портов

- Разобрали тайм-ауты проверок с кодом 124 при работающем трафике через основной узел.
- Трассировка выявила цикл get_new_port() между 49150 и 49151 при заполненном кэше из 256 отметок диапазона 48900–49151. Диагностический JSON прошёл проверку Xray.
- Перед изменениями сохранены резервные копии скриптов проверки, SOCKS auto-switch и кэша.
- В test.sh и socks_auto_switch.sh добавлено освобождение записи кэша временного порта; оба файла прошли sh -n. Удалены только устаревшие отметки диапазона 48900–49151.
- После исправления оба узла возвращают HTTP 204; HA показывает оба узла онлайн, 0 ошибок и RTT 325/369 мс. Число отметок остаётся равным 4.
- Режим оставлен primary; длительная проверка auto и контролируемый failover/recovery остаются незавершёнными.
