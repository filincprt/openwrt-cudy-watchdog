- Пользователь вернул режим Auto, последнее считанное состояние MODE=auto, ROUTE=AnMllbuc.
- Причина не установлена. Следующий шаг — read-only проверка persistence Xray-exclude после reboot и диагностика healthchecks/logs watchdog. Никаких переключений узлов до анализа.

- До и после теста PassWall2 оставался в `auto`, маршрут `AnMllbuc`; `zapret2` снова `running=true`.
- `/etc/init.d/firewall restart` выдал предупреждение `Section passwall2 option 'reload' is not supported by fw4`; считать тест fw4 незавершённым.
- Следующая проверка — автозапуск обеих служб и реальная сохранность правил после reboot. Не проводить без предварительной проверки ссылок автозапуска.

Наличие правил в runtime nftables подтверждено; счётчики и устойчивость после firewall restart/reboot ещё не проверены.
